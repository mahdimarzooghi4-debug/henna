# Fund 001 — شروع ماژول منابع حمایت و اعتبار محدود

**وضعیت:** نخستین کد دامنه و آزمون‌های پایه؛ نه صفحه Fund، نه فعال‌سازی طرح، نه دفترکل نهایی و نه امکان پرداخت.

**مرجع:** [معماری حنا، بخش ۷](../architecture/HANA-FULL-PRODUCT-NATIONAL-ARCHITECTURE-v1.0.md)، [ERD مفهومی](../architecture/HANA-DOMAIN-ERD-draft.md)، [جدایی اعتبار از وجه نقد](../adr/ADR-014-WALLET-REFUND-OPTIONAL-CASHOUT.md).

## پیاده‌سازی

- `src/Hana.Domain/Funding/ApprovedCreditAllocation.cs`، مدل immutable تخصیص حمایتیِ **پس از تصمیم تأییدشده**: شناسه تخصیص، منبع تأمین، طرح، سازمان در صورت وجود، حساب مشمول، مبلغ ریالی مثبت، نسخه احراز استحقاق، شروع/انقضا و شناسه ممیزی تصمیم. **نام کلاس/سازنده جایگزین استعلام واقعی تأمین مالی و بررسی دسترسی نیست** و مدل فعلاً فقط ساختار داده معتبر را بررسی می‌کند.
- `src/Hana.Domain/Funding/RestrictedCreditPosition.cs`، تصویر خواندنی اعتبار تخصیص‌یافته، رزروشده، مصرف‌شده، منقضی‌شده و باقی‌مانده؛ منع جمع کسور بیش از تخصیص و محاسبه دسترس‌پذیری در بازه اعتبار. اعتبار محدود نه موجودی نقدی و نه قابل برداشت به شبا است.
- `tests/Hana.Domain.Tests/Funding/`، آزمون مستقل برای شناسه/منبع/approval لازم، مبلغ مثبت، سازمان اختیاری، نرمال‌سازی تاریخ UTC، مهلت انحصاری expiry، غیرمجازبودن مصرف پیش/پس از اعتبار، جلوگیری از مصرف بیش از مانده و overflow عددی.
- `Hana.slnx` و CI اصلاح شدند تا `dotnet test Hana.slnx --configuration Release --no-build` اجرا شود.

## مرزهای حیاتی قبل از فعال‌سازی واقعی

- **هیچ API عمومی تغییر موجودی، تخصیص یا پرداخت ایجاد نشده است**؛ فرایند ثبت مشمول به تخصیص اعتبار متصل نشده است.
- منبع قطعی اعتبار باید ledger تراکنشی با approval احرازشده، بودجه/قرارداد واقعی، idempotency import/تخصیص، actor و tenant permission و outbox باشد. محاسبه این کلاس از snapshot به‌تنهایی در برابر دو سفارش هم‌زمان امن نیست.
- قوانین جزئی D03–D06، ترتیب مصرف چند منبع، سیاست انقضا و بازگشت اعتبار پس از refund، اجزای مالیات و کارمزد باید پس از تصمیم مصوب و قرارداد عملیاتی پیاده شوند؛ آنها از این اسکلت استنتاج نمی‌شوند.
- **فریم صفحه Fund در فایل فیگمای قابل‌دسترسی فعلی پیدا نشده**؛ برای جلوگیری از ساخت UI حدسی در فاز فرانت، فعلاً کد backend domain+test را پیش بردیم. طراحی Fund و پرتال سازمان طبق مرجع فیگمای تأییدشده اضافه می‌شود.
