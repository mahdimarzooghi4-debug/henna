# Frontend 026 — بازیابی قابل‌مشاهدهٔ دستهٔ ازانتشارافتاده در اپ خریدار

## دامنهٔ مصوب

همان نمای عمومی مرور کالا در اپ مصرف‌کننده (فریم‌های `476:4` و `478:22` که در Frontend 015/016 از سوی مالک تأیید شده‌اند). این تغییر در وضعیت «دسته‌بندی‌ها» و جست‌وجوی همان صفحه است و به طرح **DRAFT / NOT APPROVED** مرحلهٔ دوم ثبت‌نام فروشنده در Frontend 025 وابسته نیست.

## رفتار اجرایی

- اگر یک لینک سرد `hana://browse?categoryId=...` یا گرم/برگشت از جزئیات، دسته‌ای را درخواست کند که **فهرست دسته‌های منتشرشدهٔ معتبر HTTP 200** دیگر ندارد، اپ فیلتر را حذف می‌کند، صفحه را به ۱ برمی‌گرداند و جست‌وجوی فارسی کاربر را حفظ می‌کند. پیام قابل‌دسترس «دسته‌بندی انتخاب‌شده دیگر منتشر نیست؛ همهٔ دسته‌ها نمایش داده می‌شوند» زیر همان بخش دسته‌بندی‌ها نمایش داده می‌شود؛ اگر دسته‌های منتشرشده صفر باشند، باز هم پیام پنهان نمی‌شود.
- پیش از درخواست جدید، نتیجهٔ محصول قبلی invalid/abort و حالت loading می‌شود؛ پاسخ دیررسِ HTTP قبلی نمی‌تواند به‌عنوان کالای این query نمایش داده شود. فقط دادهٔ منتشرشدهٔ public API خوانده می‌شود.
- `503`، پاسخ معیوب یا قطعی فهرست دسته‌ها اثبات حذف انتشار نیست؛ فیلتر، جست‌وجو و صفحهٔ درخواستی حفظ می‌شوند و پیام حذف انتشار ساخته نمی‌شود. UUID با حروف کوچک/بزرگ متفاوت با همان دستهٔ واقعاً منتشرشده تطبیق می‌یابد و chip درست انتخاب می‌شود.
- انتخاب دسته/همهٔ دسته‌ها، جست‌وجوی معتبر تازه یا صفحه‌بندی، پیام بازیابی قدیمی را پاک می‌کنند. URI ورودی همچنان محدود به قرارداد عمومی Frontend 020 است؛ لینک تأییدنشده یا اطلاعات حساب وارد آن نمی‌شوند.

## آزمون و مرز صحت

`tests/mobile-buyer-category-recovery-smoke.mjs` خودِ `BuyerBrowseController` و `MobileCatalogClient` مورد استفادهٔ Expo را با HTTP حافظه‌ایِ **صرفاً CI** آزمایش می‌کند: لینک سرد صفحهٔ ۲، حذف دسته و حفظ جست‌وجوی فارسی، abort/پاسخ دیررس، `503` و پاسخ نامعتبر بدون بازیابی کاذب، لینک گرم، پاک‌شدن پیام، UUID با حروف متفاوت و حضور پیام با `accessibilityRole=alert` در سورس shipping. این تست در job موبایل CI اجرا می‌شود. TypeScript و export اندروید به‌همراه گیت‌های نصب‌شدهٔ Android/iOS قبلی باید سبز باشند؛ **این تست جدید ادعای سناریوی حذف دسته روی دستگاه فیزیکی یا fixture native ندارد.**

قیمت، موجودی، شهر قابل خرید، فروشندهٔ فعال، سبد خرید، پرداخت، دادهٔ production و طرح/قرارداد مرحلهٔ دوم فروشنده با این گام اضافه نشده‌اند. طرح Frontend 025 همچنان نیازمند تأیید صریح مالک است.
