# Geography 002 — اتصال استان و شهر به مسیر دادهٔ خریدار در وب و Expo

**دامنه:** تکمیل اتصال امن API مرجع استان/شهرِ Geography 001 به کلاینت‌های مصرف‌کننده. صفحهٔ جغرافیا، انتخاب نشانی و خرید هنوز طرح مصوب/دامنهٔ اجرایی جداگانه دارند.

## تحویل وب

سه مسیر server-side و same-origin در Next.js افزوده شد:

- `GET /api/geography/provinces`
- `GET /api/geography/cities?provinceId=<uuid>`
- `GET /api/geography/cities/{id}`

هر سه به `/api/v1/geography/...` واقعی ASP.NET وصل می‌شوند؛ URL سرور از `HANA_API_BASE_URL` خوانده و در production فقط با HTTPS پذیرفته می‌شود. بازگشت به مقصد خارجی/redirect بالادست، عبور cookie/bearer مرورگر، query اضافه، provinceId مفقود/تکراری یا شناسهٔ نامعتبر مجاز نیست. فقط `id/name/slug` استان و `id/provinceId/name/slug` شهر پس از اعتبارسنجی برمی‌گردد؛ metadata مانند وضعیت داخلی، فروشنده یا قابلیت تحویل حذف می‌شود. پاسخ فهرست شهری که استانش با درخواست یکی نباشد به جای نمایش، `503` می‌گیرد.

## تحویل Expo

`MobileGeographyClient` در `apps/mobile-consumer/src/mobile-geography.ts` همین سه خواندن عمومی را از API ASP.NET انجام می‌دهد. قرارداد پیکربندی امن `safeApiBaseUrl` فعلی را استفاده می‌کند؛ bearer از `SecureStore` نمی‌گیرد و کوکی نمی‌فرستد. ورودی نامعتبر پیش از fetch وضعیت `invalid`، شهر موجود `ok`، شهر پنهان/ناشناخته `notFound`، و قطعی/پاسخ نامعتبر `unavailable` دارد. `items: []` فقط برای پاسخ واقعی و معتبرِ 200 به معنی نبود شهر قابل انتخاب است.

## آزمون

- وب: سرور HTTPS ایزوله و Next build واقعی در `tests/web-geography-gateway-smoke.mjs`، با کوکی مرورگر آزمایشی؛ تست پاکسازی فیلدهای اضافی، جلوگیری از ارسال credential، استان اشتباه، فهرست خالی معتبر، 400/404/503 و no-store.
- موبایل: `tests/mobile-geography-smoke.mjs`، transport مصنوعی صرفاً در CI برای URL ناامن، اعتبار ID، عدم نشت اطلاعات عملیاتی، عدم عبور credential، خطای شبکه و نتیجهٔ فهرست خالی.
- smoke بدون `HANA_API_BASE_URL`: سه مسیر معتبر باید 503 بدهند؛ شناسه استان مفقود باید 400 بدهد.

## محدودیت محصول

`SELECTABLE` بودن استان و شهر **اجازه انتخاب یک هویت مکانی است، نه آمادگی فعالیت حنا در آن شهر**. این قرارداد هیچ وعدهٔ پوشش فروشنده، قیمت، موجودی، سفارش، پرداخت، سرویس لجستیک یا فعال‌بودن شهر نمی‌دهد. اطلاعات مکانی واقعی production هنوز از منبع رسمی/مورد توافق وارد نشده و فرم/فریم مصوب buyer address و انتخاب شهر نیز در فیگمای متصل موجود نیست. هیچ صفحه، دادهٔ ساختگی، شهر پیش‌فرض یا انتخاب خودکار شهر به اپ یا وب اضافه نشده است.
