# Credit Allocation 002 — نگاشت نیازهای خانوار

- **Business:** دسته‌بندی کیفی به نگاشت صریح نسخهٔ ۱ تبدیل می‌شود؛ وزن‌های Credit Allocation 001 ثابت‌اند.
- **Backlog:** Credit & Programs / Map qualitative household assessment v1.
- **Sprint:** نگاشت قطعی و آزمون دسته‌ها، مرزهای سنی، خانوار یک‌نفره، دادهٔ ناقص و سقف امتیاز.
- **Code Review و CI:** بررسی همین PR و چهار گیت backend، web، mobile و Android.
- **Stage/QA/Release:** تغییر فقط امتیازسازی خالص است. پیش از تخصیص واقعی، قرارداد دادهٔ سازمان، نگهداری نسخه کنار محاسبه، QA عملیاتی و Release Approval لازم است.

HouseholdNeedScoringV1 دسته‌های کیفی را به امتیاز تایپ‌شده تبدیل می‌کند. امتیازهای سنی اعشاری‌اند و تا ۳ محدود می‌شوند. گروه‌های سنی باید همهٔ اعضا را پوشش دهند؛ برای افراد ۶۰+ نیاز عملی به حمایت صریحاً ثبت می‌شود و سن به‌تنهایی امتیاز ندارد. دادهٔ ناقص یا ناسازگار خطا می‌دهد؛ صفر جایگزین unknown نمی‌شود. جنسیت وارد امتیازدهی نیست و تشخیص پزشکی جزئی دریافت نمی‌شود. API، DB، wallet و payment تغییری ندارند.
