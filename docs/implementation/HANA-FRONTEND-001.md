# پیاده‌سازی فرانت‌اند ۰۰۱ — پایه بصری و دو فریم از فیگما

**وضعیت:** کد اولین صفحات وب خریدار و ثبت‌نام فروشگاه نوشته شده؛ هنوز به API احراز هویت/ثبت فروشگاه متصل نیستند.  
**فناوری:** Next.js + React + TypeScript + CSS، هماهنگ با [ADR-045](../adr/ADR-045-HANA-TECHNOLOGY-STACK-ASPNET-CORE-DOTNET-10-LTS.md).  
**مرجع طراحی:** [فایل فیگمای حنا](https://www.figma.com/design/uREafnhmH5dDRwPraBOmuk/henna-platform).

## دقیقاً کدام فریم‌ها مبنا قرار گرفتند؟

- [Foundations، گره 8:4](https://www.figma.com/design/uREafnhmH5dDRwPraBOmuk/henna-platform?node-id=8-4): پالت حنایی `#B5523B`، بژ `#D7B895`، سبز نفتی `#0F5B5A`، زیتونی `#8A9A6B`، ذغالی `#2D2D2D` و کرم `#F7F3ED`، مقیاس فاصله ۴/۸/۱۲/۱۶/۲۴/۳۲، خانواده تایپوگرافی Vazirmatn و اصل رابط آرام و راست‌به‌چپ.
- [ورود دسکتاپ، گره 160:40](https://www.figma.com/design/uREafnhmH5dDRwPraBOmuk/henna-platform?node-id=160-40): هدر و لوگوی خروجی گرفته‌شده از **گره واقعی Figma**، تیتر «ورود به حنا»، ورودی موبایل، دکمه دریافت کد، توضیح حساب واحد و پیوند ثبت‌نام فروشگاه. مسیر `/auth`.
- [ثبت‌نام فروشگاه دسکتاپ، گره 160:77](https://www.figma.com/design/uREafnhmH5dDRwPraBOmuk/henna-platform?node-id=160-77): عنوان، مرحله‌های ثبت‌نام، شش فیلد اولیه، یادداشت احراز مدارک و دکمه ادامه. مسیر `/seller/register`.

**وضعیت فایل فیگمای متصل هنگام این گام:** خروجی metadata صفحه `00 • Foundations` شامل فریم‌های فوق بود؛ فریم تأییدشده صفحه اصلی فروشگاه در خروجی موجود نبود، پس `/` فقط صفحه راهنمای موقت با لینک دو مسیر است، نه طراحی ساختگی صفحه اصلی. **صفحه لجستیک ادمین طبق ADR-046 در زمان طراحی آن بخش اضافه می‌شود.**

## چه چیزی کار می‌کند؟

1. layout فارسی `lang=fa` و `dir=rtl`، CSS variables بر اساس رنگ‌های فیگما، فرم و هدر مشترک، طراحی واکنش‌گرا.
2. تصویر واقعی لوگوی فریم Figma به شکل asset محلی ذخیره شده و URL موقت Figma در برنامه باقی نمانده است.
3. ورودی‌های تعاملی، برچسب مرتبط با input، پیام‌های قابل‌خواندن با screen reader و اعتبارسنجی ابتدایی ۰۹ + ۱۱ رقم و کدپستی ۱۰رقمی؛ ارقام فارسی و عربی پیش از بررسی نرمال می‌شوند.

## مرز تعمدیِ نسخه فعلی

- **کد تأیید ارسال نمی‌شود**؛ پس از ورود شماره معتبر، پیام صریح «سرویس هنوز متصل نیست» نشان داده می‌شود. هیچ توکن، نشست یا موفقیت جعلی ایجاد نمی‌شود.
- **اطلاعات فروشگاه به سرور ارسال یا در پایگاه داده ذخیره نمی‌شود**؛ فرم فعلاً فقط تجربه ظاهری و اعتبارسنجی اولیه است و بعداً باید از طریق backend ASP.NET Core و قرارداد واقعی متصل شود.
- خانواده Vazirmatn از فیگما در CSS نام‌گذاری شده اما فایل فونت در این مرحله وارد مخزن نشده؛ تا تأمین دارایی دارای مجوز، Tahoma/Arial fallback است و بازبینی بصری دقیق با فونت نهایی بعداً لازم می‌شود.
- اجرای موفق build و smoke در GitHub Actions باید در run همان commit بررسی شود؛ این تست‌ها **جایگزین تست E2E احراز هویت/ثبت فروشگاه، تست چندعرضی مرورگر و بازبینی بصری با فریم Figma نیستند**.

## گام بعدی

پس از تأیید روند صفحات موجود، ادامه screen inventory از طراحی واقعی Figma و قرارداد backend برای OTP/هویت و ثبت فروشگاه. پیاده‌سازی بخش‌های UI دارای مرجع انجام می‌شود؛ صفحه‌های فاقد طراحی مرجع به‌صورت محصول قطعی حدس زده نشوند.
