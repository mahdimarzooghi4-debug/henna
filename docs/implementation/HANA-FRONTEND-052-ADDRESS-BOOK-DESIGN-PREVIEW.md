# Frontend 052 — پیش‌نمایش صفحهٔ نشانی خریدار

## مبنای طراحی

- Figma: `WEB / 13 Addresses`، node `245:1140`
- مسیر وب: `/account/addresses`
- محدوده: چیدمان راست‌چین صفحه، منوی حساب، فرم نشانی، اعتبارسنجی ورودی‌ها و انتخاب نقطه روی نقشه.

## نقشه

صفحه از کاشی‌های برداری/تصویری OpenStreetMap با انتساب آشکار مشارکت‌کنندگان استفاده می‌کند. نقشه تا درخواست صریح کاربر برای موقعیت دستگاه، دسترسی موقعیت جغرافیایی را نمی‌گیرد. جابه‌جایی نقشه نقطه را انتخاب می‌کند؛ مختصات در همین رابط می‌مانند و به سرور ارسال نمی‌شوند.

نشانی کاشی از `NEXT_PUBLIC_HANA_MAP_TILE_URL` قابل جایگزینی است. مقدار پیش‌فرض در این پیش‌نمایش، `https://tile.openstreetmap.org/{z}/{x}/{y}.png` است. سرویس کاشی عمومی OSM بدون SLA ارائه می‌شود و باید برای بار تولیدی متناسب با سیاست استفادهٔ آن یا با یک ارائه‌دهنده/میزبان عملیاتی جایگزین شود: https://operations.osmfoundation.org/policies/tiles/

## محدودیت فعلی

- API و جدول ذخیره‌سازی نشانی خریدار هنوز وجود ندارد؛ دکمهٔ فرم فقط ورودی‌ها را بررسی می‌کند و صریح می‌گوید چیزی ذخیره نشده است.
- فهرست نشانی‌ها خالی است؛ هیچ نشانی، شهر، مخاطب یا مختصات نمونه نمایش داده نمی‌شود.
- کدپستی اختیاری است؛ شمارهٔ همراه و کدپستی فارسی/عربی پیش از اعتبارسنجی به رقم ASCII تبدیل می‌شوند.
- این صفحه سفارش، هزینهٔ ارسال، سرویس‌دهی شهر یا وضعیت لجستیک ایجاد نمی‌کند. اتصال آینده باید با API واقعی حساب خریدار و قرارداد Mono انجام شود.
- پرداخت در محل مطابق ADR-009 نمایش داده نشده است.
