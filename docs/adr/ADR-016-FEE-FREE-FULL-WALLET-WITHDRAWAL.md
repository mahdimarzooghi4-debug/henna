# ADR-016 — عودت بانکی کیف پول بدون کارمزد برای مشتری

**وضعیت:** تصویب‌شده بر اساس تصمیم مالک محصول  
**تاریخ ثبت:** ۲۰۲۶-۰۹-۱۹  
**حوزه:** Wallet, Withdrawal, Bank Transfer, Finance, Ledger, UI  
**وابسته به:** [ADR-013 — بازپرداخت کامل](ADR-013-FULL-BUYER-REFUND-ON-VALID-CANCELLATION.md)، [ADR-014 — کیف پول و عودت درخواستی](ADR-014-WALLET-REFUND-OPTIONAL-CASHOUT.md)، [ADR-015 — شبای خود مشتری](ADR-015-WITHDRAWAL-TO-OWN-VERIFIED-IBAN.md)

## تصمیم تصویب‌شده

**درخواست عودت وجه نقد قابل برداشت از کیف پول حنا برای مشتری بدون کارمزد است؛ تمام مبلغ درخواستیِ تأییدشده باید به شبای متعلق به همان مشتری واریز شود.** کارمزد بانکی، پردازش یا سرویس انتقال نباید از مبلغ درخواستی مشتری کسر شود یا جداگانه از او مطالبه شود.

هزینه واقعی انتقال بانکی، در صورت وجود، باید طبق قرارداد تأمین‌کننده و سیاست مالی کسب‌وکار **خارج از مبلغ مشتری** ثبت/تأمین شود؛ این ADR درباره نرخ کارمزد تأمین‌کننده یا نحوه تقسیم هزینه بین کسب‌وکارهای حنا و طرف‌های بانکی تصمیمی نمی‌گیرد.

## قاعده نمونه حسابداری

```text
available_refundable_wallet_irr >= withdrawal_requested_irr > 0
buyer_withdrawal_fee_irr = 0
bank_transfer_principal_irr = withdrawal_requested_irr
buyer_bank_credit_irr = withdrawal_requested_irr

هزینه عملیاتی انتقال، اگر وجود دارد:
business_transfer_cost_irr >= 0  // جدا از مبلغ مشتری
```

مثال صرفاً برای شرح سیاست: درخواست عودت ۱۰۰٬۰۰۰ تومان → واریز ۱۰۰٬۰۰۰ تومان به شبای تأییدشده مشتری؛ هیچ کارمزدی از کیف پول مشتری یا مبلغ واریزی کم نمی‌شود. مثال تعرفه بانکی واقعی نیست.

## الزامات تجربه، API و تطبیق

1. پیش از تأیید درخواست، مبلغ برداشت و «کارمزد مشتری: صفر» نمایش داده شود؛ «مبلغ قابل واریز» با مبلغ درخواست یکسان باشد.
2. مبلغ درخواست از موجودی نقدی قابل برداشت رزرو شود؛ برداشت هم‌زمان و خرج‌کردن همان وجه ممنوع.
3. مالکیت شبا طبق ADR-015 تأیید شود؛ نتیجه نامعلومِ استعلام یا انتقال به‌معنای موفقیت نیست.
4. ledger مبلغ اصلی انتقال، کارمزد مشتری (= صفر) و هزینه احتمالی عملیاتی کسب‌وکار را جدا ثبت کند؛ اگر بانک یا تأمین‌کننده مبلغ کمتر از اصل را به حساب مشتری واریز کند، درخواست موفقِ تسویه‌شده تلقی نشود تا مغایرت بررسی/جبران شود.
5. شکست و callback تکراری باعث دوباره‌کسر از کیف پول یا دوباره‌واریز به بانک نشود.

## موارد باز

- **تصویب‌شده در [ADR-017](ADR-017-WALLET-WITHDRAWAL-WITHIN-72-HOURS.md):** مهلت عودت حداکثر ۷۲ ساعت است. مبدأ دقیق SLA در فرایند احراز/پذیرش درخواست، حداقل/حداکثر مبلغ درخواست و سقف تعداد درخواست‌ها هنوز باید در قرارداد اجرایی تکمیل شوند.
- اینکه حنا هزینه واقعی تأمین‌کننده را از کدام حساب/سرفصل کسب‌وکار تأمین می‌کند و چگونه با صورتحساب بانکی تطبیق می‌دهد.
- قیود بانکی/قراردادی یا تنظیمات مجاز که پیش از انتشار عمومی نیازمند بررسی مالی و حقوقی‌اند؛ **تصمیم به صفر بودن کارمزد مشتری نباید بی‌صدا نقض شود**.

## آزمون پذیرش

- درخواست مبلغ X از موجودی واجدشرایط به شبای خود مشتری، مبلغ X در حساب مقصد و کارمزد مشتری صفر ثبت می‌کند.
- هزینه واقعی تأمین‌کننده، اگر وجود دارد، مبلغ اصلی مشتری را کاهش نمی‌دهد.
- اعتبار حمایتی و وجه محدودشده از مسیر نقدسازی عبور نمی‌کند.
- خطای بانکی و retry هیچ کسر یا واریز مضاعفی ایجاد نمی‌کنند.
