# ADR-031 — مهلت یک‌ساعته گزارش کسری اقلام پس از دریافت واقعی سفارش

**وضعیت:** تصویب‌شده توسط مالک محصول؛ استثناهای گزارش دیرهنگام و اختلاف زمان تحویل نیازمند سیاست اجرایی مستقل  
**تاریخ ثبت:** ۲۰۲۶-۰۹-۲۰  
**حوزه:** Buyer Incident, Missing Items, Support, Customer Receipt, Refund  
**مکمل:** [ADR-030 — مهلت گزارش خرابی](ADR-030-CUSTOMER-DAMAGE-REPORT-WITHIN-ONE-HOUR-OF-RECEIPT.md)، [ADR-021 — گزارش کسری و خرابی با عکس](ADR-021-ITEM-SHORTAGE-DAMAGE-PHOTO-SELLER-RESOLUTION.md)، [ADR-022 — مقصد وجه جبران](ADR-022-ITEM-ISSUE-REFUND-TO-WALLET-OPTIONAL-WITHDRAWAL.md)

## تصمیم تصویب‌شده

**مشتری برای ثبت گزارش کسری قلم یا تعداد کالا هم، مانند خرابی کالا، حداکثر یک ساعت از دریافت واقعی سفارش فرصت دارد.** گزارش به پشتیبانی حنا می‌رسد؛ صرف ثبت گزارش به معنی تأیید خودکار کسری یا استرداد وجه نیست.

- مبدأ ساعت در ارسال، **دریافت واقعی سفارش توسط مشتری** است، نه handoff فروشنده به پیک، تخصیص پیک یا اعلام رسیدن پیک.
- مبدأ ساعت در دریافت حضوری، **دریافت واقعی سفارش توسط مشتری** است، نه آماده‌شدن سفارش.
- پایان مهلت، **ثبت اولیه گزارش نزد پشتیبانی حنا** است؛ زمان بررسی/تأیید پشتیبانی جزو یک ساعت گزارش مشتری نیست. گزارش معتبر ثبت‌شده در مهلت با بررسی دیرتر نامعتبر نمی‌شود.
- کسری کالا مأموریت بازپس‌گیری فیزیکی ندارد؛ مقررات جمع‌آوری یک‌ساعته و جریمه تأخیر فروشگاه طبق ADR-025 تا ADR-029 مختص **مرجوعی کالای خرابِ تحویل‌شده** هستند و به کسری اقلام تعمیم داده نمی‌شوند.
- اگر پرونده کسری به بازپرداخت تأییدشده برسد، سهم نقدی طبق ADR-022 ابتدا به کیف پول قابل‌استرداد مشتری و اعتبار محدود به منشأ خود بازمی‌گردد؛ عودت بانکی فقط به درخواست مشتری طبق ADR-015 تا ADR-017 است.

## قرارداد API و داده

برای `MISSING_ITEM | DAMAGED_ITEM`:
```text
incidentReportDueAt = customerReceivedAt + 60 minutes
incidentReportedAt <= incidentReportDueAt
```

`customerReceivedAt` زمان معتبر دریافت واقعی خریدار، `incidentReportedAt` زمان ثبت گزارش در سرور و `supportApprovedAt` زمان تصمیم مستقل پشتیبانی‌اند. در API می‌توان `incidentReportDueAt` عمومی را برای هر دو نوع گزارش ارائه کرد؛ `damageReportDueAt` مصوب ADR-030 معادل اختصاصی خرابی است. پرونده‌های ثبت‌شده نباید به‌خاطر طولانی‌شدن بررسی پشتیبانی خودکار منقضی شوند.

## QA

1. سفارش ساعت ۱۲:۰۰ به مشتری رسیده، گزارش کسری ساعت ۱۲:۵۹ ثبت شده: در مهلت است، حتی اگر پشتیبانی بعد از ۱۳:۰۰ بررسی کند.
2. گزارش کسری دقیقاً ساعت ۱۳:۰۰ ثبت شده: در مرز ۶۰ دقیقه است.
3. سفارش ساعت ۱۱:۰۰ به پیک تحویل و ساعت ۱۲:۰۰ به مشتری رسیده: شروع مهلت گزارش کسری ساعت ۱۲:۰۰ است.
4. گزارش کسریِ تأییدشده نباید `SELLER_RETURN_COLLECTED` یا جریمه تأخیر بازپس‌گیری کالای خراب بسازد.
5. گزارش تکراری درباره همان قلم/تعداد نباید جبران مضاعف بسازد.
