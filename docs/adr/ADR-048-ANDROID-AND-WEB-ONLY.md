# ADR-048 — حذف اپ بومی iOS و ادامهٔ Android و وب

**وضعیت:** مصوب و لازم‌الاجرا  
**تاریخ:** ۲۰۲۶-۰۹-۲۶  
**جایگزین:** [ADR-047 — اولویت وب خریدار و تعویق iOS](ADR-047-BUYER-WEB-FIRST-IRAN-IOS-NATIVE-DEFERRED.md)

## تصمیم

- اپ native حنا فقط برای Android ساخته و نگهداری می‌شود. پیکربندی Expo صریحاً `platforms: ["android"]` است.
- اپ بومی iOS، build و شبیه‌ساز iOS، اسکریپت‌های اجرای iOS و تست‌های native iOS از مخزن فعال حذف می‌شوند.
- تجربهٔ وب خریدار باید در مرورگر موبایل، از جمله مرورگر iPhone، ادامه پیدا کند. حذف اپ بومی iOS به معنی حذف دسترسی وب با iPhone نیست.
- gateهای CI همین چهار مورد هستند: backend، web، mobile و Android. هیچ gate یا release بومی iOS اجرا نمی‌شود.
- بازگرداندن پشتیبانی native iOS فقط با تصمیم تازهٔ مالک محصول و ADR جایگزین انجام می‌شود.

## محدوده

این تصمیم به صفحه‌ها و قراردادهای backend، وب واکنش‌گرا، داده‌های کسب‌وکار یا نقش‌های کاربری تغییری نمی‌دهد. پشتیبانی داخلی کتابخانه‌های عمومی از پلتفرم‌های Apple به‌تنهایی به معنی پشتیبانی محصول حنا نیست.

## پیامد

توسعه و QA اپ native خریدار روی Android متمرکز می‌شود. مستندات Frontend 022 و اشاره‌های نسخه‌های پیشین به آزمایش iOS صرفاً سابقهٔ تاریخی‌اند و معیار پشتیبانی فعلی نیستند.
