# ADR-046 — بخش لجستیک در ادمین حنا، تأمین لجستیک از بیرون و طراحی مؤخر فیگما

**وضعیت:** تصویب‌شده توسط مالک محصول؛ ارائه‌دهندهٔ عملیاتی در تصمیم تکمیلی ۲۰۲۶-۱۰-۲۵ مونو انتخاب شد؛ طراحی نهایی صفحهٔ لجستیک همچنان در انتظار Figma  
**تاریخ ثبت:** ۲۰۲۶-۰۹-۲۰  
**حوزه:** Admin Web, Logistics Integration, Product Scope, Figma, Third-party Service  
**مکمل:** [ADR-004 — مرز کسب‌وکار مستقل لجستیک](ADR-004-HANA-LOGISTICS-INDEPENDENT-INTEGRATION.md)، [ADR-044 — جدایی درآمد بازارگاه و لجستیک](ADR-044-SEPARATE-HANA-FIXED-INVOICE-FEE-FROM-LOGISTICS-COURIER-REVENUE.md)، [ADR-045 — پشته فناوری مصوب](ADR-045-HANA-TECHNOLOGY-STACK-ASPNET-CORE-DOTNET-10-LTS.md)

## تصمیم تصویب‌شده

1. **بخش لجستیک در پنل ادمینِ وب حنا وجود دارد / جزو دامنه مورد انتظار پنل ادمین است.** منظور، صفحه/بخش مدیریتی حنا برای تعامل و مشاهده داده‌های مورد نیاز حمل و اتصال بیرونی است؛ نه ساخت خود سامانه عملیات لجستیک در داخل هسته بازارگاه.
2. **خدمت/سامانه عملیاتی لجستیک از بیرون تأمین می‌شود** و حنا آن را از طریق API/قرارداد یکپارچه‌سازی دریافت می‌کند. بازارگاه حنا نباید ماژول جامع مدیریت ناوگان، تخصیص پیک و عملیات داخلی شرکت حمل را به‌جای سرویس بیرونی بسازد. این تصریح، تکمیل‌کننده ADR-004 است.
3. **طبق تصمیم مالک محصول در ۲۰۲۶-۱۰-۲۵، مونو ارائه‌دهندهٔ لجستیک حنا است.** وضعیت و موقعیت پیک از API مونو و با adapter سروربه‌سرور حنا دریافت می‌شود؛ کلید مونو به مرورگر نمی‌رود. پنل ادمین حنا نمای مخصوص ادمین حناست؛ پرتال کسب‌وکار مونو هم برای مشتریان دیگر مونو قابل استفاده می‌ماند.
4. **صفحه یا صفحه‌های بخش لجستیک ادمین، در زمان طراحی/ساخت همان بخش به فایل Figma حنا اضافه می‌شوند.** نبود فریم قطعی فعلی نباید به معنی حذف دائمی این قابلیت از محدوده محصول تعبیر شود؛ از سوی دیگر، تیم توسعه حق ندارد طراحی نهایی آن را بدون افزوده‌شدن/تأیید مرجع طراحی در فیگما، به‌عنوان «فریم مصوب موجود» معرفی کند.

## مرز دقیق دامنه

| متعلق به حنا | متعلق به لجستیک بیرونی |
|---|---|
| جایگاه لجستیک در navigation/پنل ادمین، سطح دسترسی ادمین، نمایش/پیگیری اطلاعات سفارش و اتصال، مدیریت وضعیت‌ها/اختلال‌های قابل مشاهده طبق قرارداد نهایی | سامانه عملیاتی مستقل حمل، ناوگان، پیک، تخصیص مأموریت، مسیر و اجرای ارسال |
| نگهداری ارجاع و وضعیت معتبر `deliveryJobId` به سفارش حنا، audit و گزارش‌های مرتبط با سفارش/خدمت حنا | مرجع وضعیت عملیاتی مأموریت حمل و صدور رویداد/پاسخ معتبر طبق API |
| اتصال امن API با حداقل داده لازم و قابلیت تطبیق قراردادی | فرآیندها و مدل درآمدی لجستیک؛ ۱۰٪ از پیک طبق ADR-044 درآمد بازارگاه حنا نیست |

**این جدول فهرست امکانات قطعیِ صفحه آینده یا اختیارات تغییر عملیات پیک را تعیین نمی‌کند.** نمایش فیلدها، اکشن‌های ادمین، سطح مشاهده/ویرایش، خطاها، محدودیت‌ها و نقش‌ها باید هنگام طراحی آن بخش و تنظیم قرارداد API مشخص شوند؛ از این اظهارنظر «پنل مدیریت کامل لجستیک/پیک در حنا» استنتاج نشود.

## پیامد طراحی و اجرا

- در screen inventory و برنامه اجرا، `Admin / Logistics` با وضعیت **مصوب در دامنه، طرح UI در انتظار الحاق به Figma** ثبت شود؛ سایر بخش‌های دارای طراحی مصوب حنا نباید به‌خاطر انتظار این فریم متوقف شوند.
- تا افزودن صفحه به فیگما، طرح/کامپوننت نهایی را به‌صورت حدسی معادل فریم مصوب نسازید. معماری interface/API و داده‌های مربوط به سفارش و وضعیت لجستیک می‌توانند براساس ADRهای موجود جلو بروند.
- نقطه اتصال backend حنا به بیرون یک integration adapter با قرارداد و مجوز مشخص است. دسترسی مستقیم پنل ادمین به پایگاه داده/کلید محرمانه سرویس لجستیک ممنوع؛ سیاست fail/retry/audit مطابق قرارداد نهایی باشد.
- انتخاب مونو به‌عنوان ارائه‌دهنده مشخص است؛ استقرار سرویس در محیط قابل دسترس حنا، آدرس استیج، tile server خودمیزبان OSM، SLA نهایی و فریم قطعی UI هنوز پیش‌نیازهای جداگانه دارند.
- پیاده‌سازی خواندنی وضعیت و موقعیت مونو در backend/BFF و صفحهٔ موجود ادمین، تا زمان دسترسی به tile server فقط مختصات و دست‌دادن به نقشهٔ دستگاه را نشان می‌دهد؛ این کار به معنی تکمیل Figma یا نقشهٔ درون‌صفحه‌ای نیست.

## معیار پذیرش

- دامنه ادمین حنا دارای جایگاه بخش لجستیک باشد ولی عملیات داخلی ناوگان در backlog بک‌اند بازارگاه به‌عنوان قابلیت بومی حنا ایجاد نشود.
- درخواست وضعیت حمل و موقعیت از مسیر adapter و با تطبیق سفارش حنا به درخواست/مأموریت Mono انجام شود؛ UI مالکیت عملیاتی لجستیک را جعل نکند.
- وقتی طراحی بخش آماده شد، فریم‌های آن با تأیید صاحب محصول به Figma افزوده و سپس screen inventory/قرارداد UI به‌روزرسانی شود؛ نبود فریم فعلی برچسب «طراحی تکمیل‌شده» نگیرد.
- گزارش درآمد حنا فقط کارمزد ثابت فاکتور را درآمد بازارگاه بداند؛ سهم پیک درآمد سرویس بیرونی است.
