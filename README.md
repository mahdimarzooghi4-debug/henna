# حنا | Henna

مخزن توسعه سامانه حنا؛ بازارگاه خریدار، فروشندگان، مدیریت و پرتال سازمان‌ها.

## شروع پروژه

پیش از کدنویسی، پیش‌نویس فنی و معماری مقیاس ملی را مرور و تصمیم‌های باز آن را تصویب کنید:

**[سند فنی و معماری حنا — نسخه ۰.۱](docs/architecture/HANA-TECHNICAL-ARCHITECTURE-v0.1.md)**

این مخزن در زمان ثبت سند، فاقد پیاده‌سازی فرانت‌اند یا بک‌اند بود. فناوری‌ها، اهداف دسترس‌پذیری و قواعد مالی درج‌شده در سند، پیشنهاد اولیه و نیازمند تأیید هستند.
